## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/hasnain23233/Demo-web-project.git
```

Navigate into the project

```bash
cd Demo-web-project
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open in your browser

```
http://localhost:5173
```

Build for production

```bash
npm run build
```
